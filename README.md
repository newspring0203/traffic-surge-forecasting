# 고속도로 교통량 급증 예측

고속도로 센서 기록을 바탕으로 **30분 뒤의 5분 구간에 차량이 몇 대 통과할지** 예측합니다. 경부고속도로에서 LSTM과 Transformer를 비교한 연구를 이어, 이번에는 전체 평균에 가려지는 오차에 주목했습니다. 지난주 같은 시간에는 큰 변화가 없었는데 이번 주에 차량 통과 대수가 크게 늘어난 구간을 따로 살펴봤습니다. [원래 연구 코드 (GitHub)](https://github.com/mgs06380/SNA_Research)

## 핵심 결과

PeMS08에서 기본 XGBoost는 이런 급증 사례의 **96.15%**에서 실제보다 적은 차량 대수를 예측했습니다. 학습 중 이 사례의 오차를 더 크게 반영하면 예측이 개선되는지 확인했습니다. PeMS08에서 가중치를 정하고, 별도 데이터인 PeMS03에서 같은 설정으로 모델을 다시 학습해 비교했습니다.

| PeMS03 모델 | 전체 MAE ↓ | 급증 MAE ↓ | 비반복 급증 MAE ↓ |
|---|---:|---:|---:|
| 기본 XGBoost | 17.59 | 33.50 | 40.96 |
| 가중 XGBoost | 17.73 | 32.10 | 39.06 |
| LSTM | 17.25 | 31.53 | 38.36 |

MAE는 예측값과 실제값이 평균 몇 대 차이 나는지를 나타냅니다. 기본 XGBoost에 비해 가중 XGBoost의 **비반복 급증 MAE는 4.6% 줄었고, 전체 MAE는 0.8% 늘었습니다.** 표의 LSTM은 비교한 모델 가운데 세 지표가 가장 낮았습니다. 신경망은 시드 하나로 학습 데이터를 5회 반복해 학습한 결과입니다.

이 결과로 실제 급증 구간에서 차량 대수를 얼마나 정확하게 예측했는지 알 수 있습니다. 관제 경보에 적용하려면 급증을 얼마나 자주 놓치는지, 잘못된 경보를 얼마나 내는지, 충분히 일찍 알리는지도 별도로 확인해야 합니다.

## 실험 설계

### 지난주 기록을 기준으로 비교

지난주 월요일 오전 8시에 같은 센서에서 차량 120대가 관측됐다면, 이번 주 월요일 오전 8시도 120대로 예측하는 것이 주간 기준선입니다. 이 값과 비교하면 최근 교통량까지 사용하는 모델이 오차를 얼마나 줄였는지 볼 수 있습니다.

릿지는 최근 관측과 주간 기록에 각각 일정한 계수를 곱해 더합니다. XGBoost와 MLP는 최근 교통량이 어느 수준인지에 따라 같은 주간 기록도 다르게 반영할 수 있습니다. LSTM은 최근 관측을 순서대로 읽으며 정보를 누적하고, Transformer는 관측 창 안의 시점들을 서로 참조합니다. 모든 모델은 각 데이터셋에서 같은 센서와 시각을 대상으로 평가했습니다.

### 반복되는 상승과 비반복 급증 구분

센서마다 차량 대수의 변동 폭이 다릅니다. 그래서 학습 구간의 30분 상승폭을 센서별로 모아 90분위수를 기준으로 삼았습니다. 이번 주 상승폭만 이 기준을 넘고 지난주 같은 시간의 상승폭은 기준 이하인 경우를 **비반복 급증**으로 분류했습니다. 이렇게 하면 두 주 모두 나타난 출근 시간대 상승을 따로 구분할 수 있습니다.

### 가중치 선택과 검증

PeMS08에서 과소예측이 관찰된 XGBoost의 입력과 트리 설정을 고정하고, 학습 사례의 가중치만 바꿨습니다. 급증 구간의 오차를 줄이는 과정에서 다른 구간까지 포함한 전체 오차가 얼마나 늘어나는지 보기 위해 두 지표를 함께 비교했습니다. PeMS08에서는 전체 MAE 증가율을 1% 이내로 제한하는 실험 기준을 적용해 1.5배를 선택했습니다.

PeMS03에서는 그 설정으로 과거 구간을 학습하고 이후 구간에서 평가했습니다. 데이터는 시간순으로 나눴으며, 정규화에 필요한 통계와 센서별 급증 기준은 각 데이터셋의 학습 구간에서 계산했습니다.

## 핵심 수식

### 예측 대상과 평가 지표

센서 $s$에서 시점 $t$에 끝나는 5분 동안의 통과 대수를 $y_{s,t}$로 씁니다. 30분은 5분 간격으로 6칸이므로 예측 대상은 $y_{s,t+6}$입니다. 주간 기준선은 이 목표 시각에서 7일(2,016칸)을 거슬러 올라간 $y_{s,t+6-2016}$입니다.

학습 구간의 30분 상승폭 $y_{s,t+6} - y_{s,t}$의 센서별 90분위수를 $\tau_s$로 정합니다. 이번 주 상승폭이 $\tau_s$를 넘고 지난주 대응 상승폭이 $\tau_s$ 이하면 비반복 급증으로 분류합니다. 평가할 때는 실제로 얼마나 증가했는지 확인한 뒤 사례를 분류합니다. 모델은 예측 시점까지 확보한 값으로 차량 대수를 예측합니다.

$$
\mathrm{MAE}_G = \frac{1}{|G|} \sum_{i \in G} |y_i - \hat{y}_i|
$$

$G$는 전체 표본, 급증 표본, 비반복 급증 표본 중 하나입니다. 잔차를 $e_i = \hat{y}_i - y_i$로 두면 절대 오차를 $\max(-e_i, 0) + \max(e_i, 0)$으로 나누어 과소예측과 과대예측이 각각 얼마나 기여했는지 확인할 수 있습니다.

### 모델의 계산 방식

| 모델 | 핵심 계산 | 비교 목적 |
|---|---|---|
| 릿지 | $\hat{y} = b + w^\top u$에 $\lambda \lVert w \rVert_2^2$ 규제를 적용합니다. | 상관된 시차 입력을 선형으로 결합했을 때의 기준 성능을 확인합니다. |
| XGBoost | $\hat{y} = b + \eta \sum_{k=1}^{K} f_k(u)$로 트리의 출력을 더합니다. | 입력의 값과 조합에 따라 다른 예측 규칙을 학습합니다. |
| MLP | $\hat{y} = W_2 \mathrm{ReLU}(W_1u + b_1) + b_2$로 계산합니다. | 고정된 위치의 시차 입력을 비선형 함수로 결합하는 효과를 확인합니다. |
| LSTM | $c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$로 상태를 갱신합니다. | 최근 관측을 시간순으로 읽으며 어떤 정보를 유지할지 학습합니다. |
| Transformer | $\mathrm{softmax}(QK^\top / \sqrt{d_k}) V$로 시점별 표현을 결합합니다. | 관측 창 안에서 어떤 시점의 정보를 참조할지 학습합니다. |

### XGBoost 학습 가중치

학습 중에는 같은 크기의 오차라도 비반복 급증에서 발생한 오차를 더 크게 반영합니다. 비반복 급증이면 $a_i = 1$, 그 외에는 $a_i = 0$으로 표시합니다. 급증 사례에 배율을 적용한 뒤, 전체 학습 표본의 평균 가중치가 1이 되도록 나눕니다.

$$
\tilde{w}_i = 1 + (\alpha - 1)a_i,\qquad
w_i = \frac{\tilde{w}_i}{\overline{\tilde{w}}},\qquad
L_{\mathrm{data}} \propto \sum_i w_i (y_i - \hat{y}_i)^2
$$

PeMS08에서 기본 XGBoost 대비 전체 MAE 증가를 1% 이내로 제한하는 실험 기준을 적용해 $\alpha = 1.5$를 선택했습니다. 이 기준은 개선 폭과 전체 성능의 절충을 비교하기 위해 설정했습니다.

## 데이터, 코드 및 재현

Python 환경에 NumPy 2.0.2, PyTorch 2.8.0, XGBoost 2.1.4를 설치합니다. 아래 명령은 프로젝트 루트에서 실행합니다. 공개 PeMS08과 PeMS03 관측 파일을 각각 `data/PEMS08.npz`와 `data/PEMS03.npz`에 둡니다. [데이터 배포본](https://github.com/guoshnBJTU/ASTGNN/tree/main/data)

```sh
python3 evaluate_stage1.py
python3 evaluate_stage2.py
python3 diagnose_stage3.py
python3 evaluate_stage4.py
python3 evaluate_stage2.py --external-pems03
```

각 단계의 지표와 개별 예측은 실행 후 `results/staged/`에 생성됩니다. 단계 1은 주간 기준선과 릿지, 단계 2는 다섯 모델 비교, 단계 3은 오차 분해, 단계 4는 학습 가중치 선택, 단계 5는 PeMS03 검증입니다.
